# Localising the interface

The interface uses [vue-i18n](https://vue-i18n.intlify.dev/). A language is a
folder of JSON files, `src/locales/<code>/<namespace>.json`, each a flat
`{ "key": "Text" }` object. A text is addressed as `namespace.key`. All
languages are equal: Russian and English ship with the project.

```ts
import { t } from '@/i18n'

t('stream.address')                          // "URL"
t('table.nOfTotal', { n: 1, total: 3 })      // parameters: "{n} of {total}"
t('common.streams', 3)                       // the word form for a number
```

`npm run i18n` checks the dictionaries against the source and against each
other; `npm run typecheck` must pass too. Both run in `make test`.

## Adding a language

1. Copy `src/locales/en` to `src/locales/<code>` (`de`, `es`, …) and
   translate the values. Keys and file names stay as they are.
2. Keep the `{parameters}` of every text.
3. Plural texts hold the forms separated by ` | `, one per plural category
   of the language in the order `Intl.PluralRules` lists them:
   `"stream | streams"` for English (one, other),
   `"поток | потока | потоков"` for Russian (one, few, many). The checker
   says which forms it expects.
4. Run `npm run i18n`.

Nothing else: the folder name is the language code, the language appears in
the switch by itself and is picked for browsers that prefer it. A text that
a language lacks is shown in English.

## Adding or changing texts

- No text for the user is written in the source: add a key to the
  namespace of the page (`stream`, `dashboard`, `diagnose`, …) in **every**
  language and use `t('namespace.key')`. Texts used on several pages live in
  `common`, units and time words in `format`.
- Name a key after what the text says, in camelCase: `addStream`,
  `playlistIsNotUpdating`.
- The same word that means different things in different places gets
  different keys (`stream.address` is a URL, `host.address` an IP address).
- A sentence is one text with `{named}` parameters. Do not build it from
  pieces: word order differs between languages. Where markup sits inside a
  sentence (a link, a `<span class="mono">`), split it into the few texts
  around the markup and keep each a meaningful phrase.
- A word that follows a number is a plural text: `t('common.streams', n)`.
- The language can change while the page is open. Components are rebuilt
  when it does, so texts in component constants are fine. Tables of texts
  kept in plain modules are wrapped in `perLocale()` and read as a call:
  `statusLabel()[status]`.
- Messages produced by the checker (the engine) are English and are shown
  as they are.

Stream"), no exclamation marks, the same register as the Russian.
